# Galeria - Gwyn e Artorias

Projeto desenvolvido para a disciplina do curso de **Análise e Desenvolvimento de Sistemas** na Univali.

## Sobre o projeto
Página web simples apresentando uma galeria de fotos dos gatos Gwyn e Artorias, com informações sobre eles.

## Tecnologias utilizadas
- HTML5
- CSS3 (estilos embutidos)

## Como visualizar
Basta abrir o arquivo `index.html` no navegador.
